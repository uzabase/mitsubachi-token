# Color / Semantic

用途で名付けられた色トークン。**アプリケーションからはこちらを参照してください。**

## primitive との関係

semantic は色を直接持たず、**primitive を参照しています。** Figma 上でも semantic 変数は
primitive 変数へのエイリアスとして定義されていて、その構造をそのまま出力しています。

```css
--color-semantic-zabuton-semi-strong: var(--color-primitive-neutral-5);
```

下の表の **Alias** 列に、それぞれがどの primitive を指しているかが出ます。色見本は参照を
解決した実際の色です。

この構造のおかげで、**primitive を上書きすれば semantic 全体が追従します。**

```css
:root {
  --color-primitive-white: #1d1d1d; /* semantic-zabuton-regular などが一斉に変わる */
}
```

### 例外の 2 件（ダークモード用）

`semantic-elevation-regular-inverse` と `semantic-elevation-semi-strong-inverse` の
2 件だけは、Figma でもエイリアスではなく生値なので参照になっていません。

**この 2 件は現在どちらも完全に透明（`#ffffff00`）です。** 今は実質的に何も描画しません。

> **将来ライトモードとダークモードが搭載される予定で、この 2 件は
> ダークモードのときだけ値がセットされる想定です。**
> 現在の透明という値は「ライトモードでは使わない」という意味なので、
> **透明であることを前提にした使い方をしないでください。**
> ダークモードが入ると実際の色が入ります。
